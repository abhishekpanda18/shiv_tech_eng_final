SHIV TECH ENGINEERING — Scroll Hero Website

HOW TO RUN:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Install the "Live Server" extension if you do not already have it.
4. Right-click index.html → Open with Live Server.

IMPORTANT:
- hero.mp4 is the supplied 1920×1080, 30fps, 8-second video.
- The hero uses object-fit: contain, so the complete video frame is visible and the bottom is not cropped.
- Scroll position controls video.currentTime.
- The rest of the page is an initial premium industrial website structure that can be customized with your actual company information, logo, product images, phone number, address and enquiry form.
